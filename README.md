**## Project Status and Responsible Use

This repository contains a conceptual framework and proof-of-concept prototype for an AI-driven personalized autism intervention guideline generator. The prototype is intended for research, demonstration, and controlled evaluation purposes only.

This system is not a production clinical system, is not a diagnostic tool, and has not been clinically validated. It should not be used to make real-world clinical, therapeutic, educational, or intervention decisions without review and approval by qualified professionals.

The prototype uses synthetic data for controlled validation. No real patient records, protected health information, or identifiable child data are included in this repository.

The system demonstrates how multi-agent orchestration, structured child-profile synthesis, developmental-domain prioritization, intervention guideline generation, SMART goal generation, milestone planning, caregiver-facing guidance, data quality checks, bias monitoring, confidence-based abstention, audit logging, and human-in-the-loop review may be organized in a responsible workflow.

AI-assisted coding tools may have been used to support implementation tasks such as scaffolding, debugging, refactoring, and documentation support. The system architecture, workflow design, governance model, validation approach, research framing, and final review remain the responsibility of the project authors.
